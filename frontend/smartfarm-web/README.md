# Smart Farm Mini — Frontend Web (Dashboard)

Giao diện người dùng trên nền web (Web Dashboard) cho hệ thống Smart Farm Mini.

## 1. Công nghệ dự kiến
- **Framework:** React 19 / TypeScript
- **Build tool:** Vite
- **Styling:** Tailwind CSS
- **Realtime:** `@microsoft/signalr`
- **Charts:** Chart.js / Recharts

## 2. Tính năng chính
- Theo dõi các chỉ số cảm biến thời gian thực (độ ẩm đất, nhiệt độ/độ ẩm không khí, nhiệt độ nước, mực nước).
- Điều khiển bật / tắt máy bơm thủ công.
- Cấu hình ngưỡng tưới tự động (Irrigation Rules).
- Báo cáo và xem lại lịch sử các lần tưới (Irrigation Logs) và cảnh báo (Alerts).
